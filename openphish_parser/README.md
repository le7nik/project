# OpenPhish Phishing URL Parser

Простой парсер, который периодически загружает бесплатный фид OpenPhish (`feed.txt`), сохраняет URL в SQLite и Excel, удаляет дубликаты и формирует итоговый отчёт.

> ⚠️ **Важно:** OpenPhish не предоставляет бесплатный доступ к полям «бренд» и «точное время обнаружения». Бренд определяется эвристически по ключевым словам в URL.
> Время фиксируется как момент, когда скрипт впервые увидел URL.

## 📋 Требования

- Python 3.9+
- Библиотеки: `requests`, `pandas`, `openpyxl`, `schedule`

## 🚀 Установка и запуск

```bash
# 1.  Установить зависимости
pip install -r requirements.txt

# 2. Запустить парсер
python parser.py

### Что делает скрипт
Каждые 5 минут запрашивает https://openphish.com/feed.txt.

Извлекает список URL (каждая строка — один URL).

Для каждого URL пытается определить целевой бренд по ключевым словам (PayPal, Microsoft, Facebook и т.д.).

Сохраняет запись в SQLite с полями url, brand, first_seen.

Благодаря ограничению UNIQUE на поле url дубликаты игнорируются.

По истечении заданного периода (по умолчанию 20 минут):

выводит в консоль время начала/окончания, общее и уникальное количество URL, топ-3 брендов;

сохраняет все собранные данные в data/phishing_report.xlsx.

⚙️ Настройка
В файле parser.py можно изменить:

DURATION_MINUTES — длительность сбора (минут).

INTERVAL_MINUTES — интервал между запросами (минут).

BRAND_KEYWORDS — словарь ключевых слов для определения бренда.

📝 Ограничения
Бренд определяется приблизительно — по вхождению ключевого слова в URL. Для точных данных нужен премиум-фид OpenPhish (JSON/CSV с полем brand).

Время обнаружения — это время, когда скрипт впервые увидел URL, а не официальное время обнаружения OpenPhish.

Бесплатный фид feed.txt обновляется не строго каждые 5 минут, а по мере появления новых фишинговых сайтов. Однако опрос каждые 5 минут гарантирует, что вы не пропустите новые записи.
